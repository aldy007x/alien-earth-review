Entry for the [Alien Field Notes: The Two Day Earth Review](https://make.fun/bounty/u-swift-raven-16-alien-field-notes-the-two-day-earth-7647b000) bounty on [make.fun](https://make.fun/bounty/u-swift-raven-16-alien-field-notes-the-two-day-earth-7647b000).

`main.py` deterministically writes a single original line of plain text — an
alien tourist's one-line review of planet Earth — to `entry.txt`:

> Visited Earth: once a year, the locals set their dessert on fire, make a wish, then blow it out. 4/5 stars — I wished for a refund.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

No network access, no environment secrets, nothing read outside this repo.
